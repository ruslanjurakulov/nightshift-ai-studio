# Exact versions of the SDKs whose behaviour a worker image must not change by
# itself. requirements.txt keeps its floors (>=); Dockerfile.worker installs with
# `-c constraints.txt`, so a rebuild can never pick up a newer major release of
# these without a reviewed change here. Raise a pin deliberately, in its own PR,
# after the test suite passes on the new version.
#
# Versions = what /home/user/venv (the environment the 5543-test suite ran in on
# 2026-10-18) has installed; all four exist on PyPI for Python 3.11, the image's
# interpreter (elevenlabs, google-genai, edge-tts as wheels, openai-whisper as an
# sdist). The repository has no lockfile and no CI pin to compare against.
elevenlabs==2.70.0
google-genai==2.26.0
edge-tts==7.2.8
openai-whisper==20250625
# imageio-ffmpeg carries the ffmpeg binary every render, probe and media-library decode runs
# (modules/render_backend.resolve_ffmpeg). It is a dependency of moviepy with no pin of its own, so each new release
# swapped that binary under the worker image, the daily-video workflow and CI without a change here: 0.6.0 ships
# FFmpeg 7.0.2, and 0.8.0 (in CI from 2026-11-03) ships FFmpeg 9.0.2, a two-major jump that also dropped options the
# suite uses (-vsync). 0.6.0 is what the last green run of the full suite installed (2026-10-26).
imageio-ffmpeg==0.6.0
