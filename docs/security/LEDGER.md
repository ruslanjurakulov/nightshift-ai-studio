# Security ledger

The single record of every security finding. Process and conventions are in
[README.md](README.md). Newest findings go at the bottom of their section.
A row is never deleted. It moves to `fixed` or `wontfix` with a reason.

**Status:** `open` = hole exists; `fixed` = merged fix and regression test;
`wontfix` = accepted risk, reason in root cause.
**Severity:** critical > high > medium > low > info (rubric in README).

## Static review: checked and clean (2026-10-01)

Recorded so these are not re-reported.

- **No `pull_request_target`, `workflow_run` or `issue_comment` triggers** in any workflow. PR-triggered
  workflows (tests, frontend, security, video-engine) receive no secrets.
- **No `${{ … }}` expressions inside `run:` scripts.** Every dispatch input and secret reaches the shell
  through `env:`, so there is no script injection from `workflow_dispatch` inputs.
- **The privacy input stays private from the browser.** `daily_video.yml` offers `privacy: public` to
  manual dispatch (repository write access needed), but the Command Center always dispatches
  `privacy: "private"` (`command-center/lib/server/github-secrets.ts`).
- **Telegram control** (`modules/telegram_control.route_command`) checks both chat id and sender id
  before any query or action, and returns actions as intents.
- **`deploy_web.yml`** keeps secrets in `env:` and stdin, pins the SSH host key, and uses
  `persist-credentials: false`. The server's forced command refuses commits that are not on `origin/main`.
- **No hardcoded secrets in tracked files.** Pattern scan (provider key prefixes, JWTs, private-key
  blocks, Slack/Telegram/GitHub/Google/Paddle token shapes) found only obvious test fixtures in
  `tests/` and `command-center/tests/`. The `.env.example` files contain blank values. Git history
  was **not** scanned: the clone is shallow.
- **Containers:** the web and worker images run as non-root users (`USER node`, `USER nightshift`).
  The web container publishes no host port, so Caddy is the only way in.
- **Python environment:** `pip-audit` of the installed, frozen dependency set reports no known
  vulnerabilities (2026-10-01).
