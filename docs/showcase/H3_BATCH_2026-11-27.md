# Showcase batch, 2026-11-27: H3 clips and NUR posters

This records what stream S11 generated for the site samples, and what we
measured and what we did not. All assets are **private** in the operator
workspace's library. Nothing was published or placed on the site. Selection
for the site happens in review, and the export goes through
`tools/export_showcase.py`.

The scratchpad these notes came from is not durable, so this file is the
record.

## How to read this

- **Audio: "stream present" is a measurement; "sound matches the prompt" is
  not.** Every clip has an AAC stream (32 kHz stereo, 6.575 s), and each one
  was checked with `ffprobe` and loudness-checked with ffmpeg `volumedetect`.
  Nobody has listened to them. **Sound match is NOT verified** for any clip.
- **Visual checks used 1 fps frame strips only.** An artefact shorter than
  about a second can be missed. Before anything goes on the site, a person
  watches it.
- **Integrity:** each downloaded file's sha256 matched the sha256 in its job
  row.
- **Clip spec:** `minimax-h3`, t2v, 768p, 6 s requested. Every file is 6.58 s
  at 24 fps: 1344x768 for 16:9, 768x1344 for 9:16.
- Audio values are **mean / peak** in dBFS.

### Flag legend

| Flag | Meaning |
| :-- | :-- |
| `SILENT` | Audio stream present but effectively silent. **Never label it as "with sound".** |
| `NORMALISE` | Peak at or near 0 dBFS. **Normalise on export.** |
| `TRIM` | Cut on export, as stated. The clip is never regenerated for this. |
| `OWNER-LOOK` | Needs the owner's look before any use. |
| `NAME` | The prompt's place name does not match the output. Use the honest name given. |
