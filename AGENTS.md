# Nightshift — Product Constitution for AI Agents

This document is a standing product brief for Codex and other coding agents. Read `CLAUDE.md` first and follow its existing security, publishing, credentials, financial, testing, and owner-approval rules. If this product vision conflicts with an operational safeguard, the safeguard wins until the owner explicitly approves a safe change.

## Mission

Build **Nightshift AI Content Operating System**: an independent, commercial-grade studio in which creators can create, edit, automate, publish, analyze, and improve content without switching among numerous AI tools and editing apps.

**Product loop:** Create → Edit → Automate → Publish → Analyze → Improve.

## Strategic principles

1. **Original model providers first.** Higgsfield, Krea, BigMotion, Ssemble, and Buzzy are competitors and benchmark sources, not preferred API resellers. Research their capabilities, identify original model developers, and prioritize officially documented direct APIs when available and legally permitted. Do not assume every model has a public API or that direct access is always cheaper.
2. **Independent workflows.** Benchmark competitor UX, creative workflows, editing, and automation; implement original Nightshift experiences rather than copying proprietary designs or relying on competitor platforms as core infrastructure.
3. **Unified creation.** Bring image, video, voice, dubbing, captions, and other supported generation workflows into one coherent project workspace with clear model capabilities, costs, and provenance.
4. **Built-in professional editing.** Users should be able to upload and edit their own images, video, and audio without needing CapCut or InShot. The product roadmap includes multi-track timelines, trim/split, transitions, subtitles, overlays, effects, audio mixing, templates, format conversion, and export. These are goals, not claims of already shipped functionality.
5. **Strategy-aware automation.** Plan content around each channel's topic, audience, brand voice, constraints, and measured performance. Reject off-topic or low-quality outputs via Topic Guard and quality checks. Do not fabricate trends or performance evidence.
6. **Multi-platform publishing.** Plan for YouTube, Instagram, and TikTok using authorized accounts, official platform APIs, and platform-specific constraints. Support repurposing, scheduling, and analytics where the platform actually permits it. Never promise unsupported API features.
7. **Human-controlled publication.** Preserve `CLAUDE.md` publishing invariants: publishing and visibility changes remain gated, per-channel auto-publish defaults off, and no browser action directly publishes or spends. New platforms must meet equivalent approval and audit requirements before launch.
8. **Financial and security discipline.** Cost optimization includes provider pricing, credits, reservations, reconciliation, retries, and margins. Unknown provider outcomes must not be treated as free. Respect the trusted gateway, lease ownership, idempotency, secrets isolation, and security gates.
9. **Measure and improve.** Close the feedback loop with attributable performance metrics, experiments, and recommendations. Distinguish verified facts from assumptions and proposed features.
10. **Commercial quality.** Prioritize original premium UX, accessibility, mobile responsiveness, reliable workflows, honest loading/error states, and testable end-to-end behavior.

## Agent checklist for every Nightshift proposal

- Does it advance the full Create → Edit → Automate → Publish → Analyze → Improve vision?
- Does it reduce unnecessary external platform dependency without sacrificing quality or compliance?
- Is the underlying model's original provider and official API verified?
- Does it integrate into the Nightshift project/editor workflow?
- Does it respect channel topic strategy, Topic Guard, Publish Gate, and user authorization?
- Are costs, credits, provider failures, security, and observability addressed?
- Are shipped functionality, prototypes, and roadmap ideas clearly distinguished?
